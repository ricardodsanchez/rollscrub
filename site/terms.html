What RollScrub promises about your files

These are the guarantees the software is built around, and they're worth stating as terms rather than marketing:

  • It never deletes anything. Files are moved to the Trash, and you empty that yourself.
  • It never moves a file to a different volume.
  • Every file is verified byte for byte against the copy being kept, immediately before it is moved.
  • It never writes inside a Photos, Lightroom, Aperture or Final Cut library.
